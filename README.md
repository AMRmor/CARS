# CARS — Prototype mini-voiture

Site de présentation du projet CARS / P01.

## Objectif

Présenter le prototype comme une plateforme R&D crédible : architecture, logique de validation, essais et journal de développement, sans inventer de performances non mesurées.

## Stack

- HTML5
- CSS3
- JavaScript natif
- SVG originaux
- GitHub Pages

## Déploiement

Le workflow `.github/workflows/pages.yml` publie automatiquement la branche `main` sur GitHub Pages.
